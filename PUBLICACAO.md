# Fluxo de publicação

1. Faça as alterações na pasta `PORTAL ALVORAR`.
2. Execute `atualizar-publicacao.ps1` nesta pasta.
3. Confira `git status`.
4. Crie o commit e envie para a branch `main`.
5. O Netlify publicará automaticamente o novo commit.

Arquivos locais, pontos de restauração, testes e planilhas de trabalho não entram na publicação.
