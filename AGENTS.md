# Instruções da pasta de publicação

- Esta pasta é exclusiva para publicar o Portal ALVORAR no GitHub e no Netlify.
- O desenvolvimento deve ser feito em `C:\Users\TAINA-COSTA\Documents\F360\PORTAL ALVORAR`.
- Antes de publicar, execute `powershell -ExecutionPolicy Bypass -File .\atualizar-publicacao.ps1` nesta pasta.
- Não copiar `_restore-points`, `.local`, testes, ferramentas, planilhas de exemplo ou dados de trabalho.
- O repositório e o site do Portal ALVORAR são independentes do F360 NORMAL.
